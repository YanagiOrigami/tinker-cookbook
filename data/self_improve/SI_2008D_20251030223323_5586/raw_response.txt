**Problem Statement – Black Nodes in Prefix of a Permutation Cycle**

For a permutation `p` of length `n` (that is, an array `p1 , p2 , … , pn` where each integer from `1` to `n` appears exactly once) we define the *orbit* of a position `v` as the infinite sequence

```
v , p_v , p_{p_v} , p_{p_{p_v}} , …
```

i.e. we repeatedly replace the current index by the value of `p` at this index.

Every element of the permutation belongs to exactly one directed cycle, therefore every orbit is a periodic repetition of the elements of this cycle.

Each position `i` is coloured **black** if `s_i = '0'` and **white** otherwise (`s` is a binary string of length `n`).

For a query `(v , k)` we are interested in the number of black positions among the first `k+1` elements of the orbit of `v`
(the starting position `v` itself is counted, then the next element, …, up to `k` steps).

Formally, let  

```
a0 = v
a_j = p_{a_{j-1}}   (j ≥ 1)
```

The answer for the query `(v , k)` is  

```
| { j | 0 ≤ j ≤ k  and  s_{a_j} = '0' } |
```

You have to answer many queries.

--------------------------------------------------------------------

### Input
The first line contains a single integer `t` (`1 ≤ t ≤ 10^4`) – the number of test cases.  

The sum of `n` over all test cases does not exceed `2·10^5`.  
The sum of `q` (the number of queries) over all test cases does not exceed `2·10^5`.

For each test case:

* The first line contains an integer `n` (`1 ≤ n ≤ 2·10^5`) – the length of the permutation.
* The second line contains `n` integers `p1 , p2 , … , pn` (`1 ≤ pi ≤ n`) – the permutation.
* The third line contains a binary string `s` of length `n`. `s_i = '0'` means position `i` is black, `s_i = '1'` means it is white.
* The fourth line contains an integer `q` (`1 ≤ q ≤ 2·10^5`) – the number of queries.
* Each of the next `q` lines contains two integers `v` and `k` (`1 ≤ v ≤ n`, `0 ≤ k ≤ 10^18`) – a query as described above.

```cpp
#include <bits/stdc++.h>
using namespace std;

struct CycleInfo {
    int len;                     // length of the cycle
    long long totalBlack;        // number of black vertices in the whole cycle
    vector<int> pref;            // prefix sums of black values, size len+1
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T;
    if(!(cin >> T)) return 0;
    while (T--) {
        int n;
        cin >> n;
        vector<int> p(n + 1);
        for (int i = 1; i <= n; ++i) cin >> p[i];
        string s;
        cin >> s;
        int q;
        cin >> q;
        
        // data for each vertex
        vector<int> cycId(n + 1, -1);
        vector<int> posInCyc(n + 1, -1);
        vector<CycleInfo> cycles;
        vector<char> used(n + 1, 0);
        
        for (int v = 1; v <= n; ++v) if (!used[v]) {
            // discover one whole cycle
            vector<int> verts;
            int cur = v;
            while (!used[cur]) {
                used[cur] = 1;
                verts.push_back(cur);
                cur = p[cur];
            }
            int L = (int)verts.size();
            CycleInfo ci;
            ci.len = L;
            ci.pref.assign(L + 1, 0);
            for (int i = 0; i < L; ++i) {
                int node = verts[i];
                int isBlack = (s[node - 1] == '0');
                ci.pref[i + 1] = ci.pref[i] + isBlack;
                // store vertex info
                cycId[node] = (int)cycles.size();
                posInCyc[node] = i;
            }
            ci.totalBlack = ci.pref[L];
            cycles.push_back(std::move(ci));
        }
        
        while (q--) {
            int v;
            long long k;
            cin >> v >> k;
            int id = cycId[v];
            const CycleInfo &ci = cycles[id];
            int L = ci.len;
            long long steps = k + 1;               // number of visited vertices
            long long full = steps / L;
            int rem = (int)(steps % L);
            long long ans = full * ci.totalBlack;
            if (rem) {
                int start = posInCyc[v];
                int endPos = start + rem;
                if (endPos <= L) {
                    ans += ci.pref[endPos] - ci.pref[start];
                } else {
                    // wrapped around the end of the cycle
                    ans += ci.totalBlack - (ci.pref[start] - ci.pref[endPos - L]);
                }
            }
            cout << ans << '\n';
        }
    }
    return 0;
}
```
