**Problem – Bob’s Budget and Deletions**

There are `n` items, the `i`‑th item initially costs `a_i` (`1 ≤ a_i ≤ 10^9`).  
Alice and Bob will play a game after the costs are possibly changed.

* The players move alternately, Alice moves first.
* In each turn the current player chooses **any** remaining item and takes it.
* The game finishes when no items are left.
* Let `A` be the total cost of the items taken by Alice and `B` the total cost of the items taken by Bob.
* The score of the game is `A‑B`.

Both players play optimally: Alice tries to maximise the final score, Bob tries to minimise it.

---

Before the game starts Bob may **modify** the set of items in the following two ways

1. **Increase** the cost of any item `i` by a non‑negative integer `x_i`.  
   The total sum of all increases must not exceed `k`:

   `Σ x_i ≤ k`.

2. **Delete** up to `m` items completely (they will not participate in the game).  
   Deleting an item costs nothing, only the number of deleted items is limited.

Bob may use both operations in any order. After all modifications the game is played on the remaining items with their final costs.

For each test case determine the minimum possible final score that Bob can enforce.



--------------------------------------------------------------------
#### Input

The first line contains a single integer `t` (`1 ≤ t ≤ 5000`) — the number of test cases.

Each test case consists of two lines.

* The first line contains four integers `n , k , m ,` and `s` (`2 ≤ n ≤ 2·10^5`,
  `0 ≤ k ≤ 10^9`, `0 ≤ m ≤ n`, `1 ≤ s ≤ 10^5`) where `s` is the sum of `n` over all test cases, guaranteed `s ≤ 2·10^5`.
* The second line contains `n` integers `a_1 , a_2 , … , a_n` (`1 ≤ a_i ≤ 10^9`).

--------------------------------------------------------------------
#### Output

For each test case output a single integer — the minimum possible score `A‑B` after Bob’s modifications and optimal play.

--------------------------------------------------------------------
#### Example

```
input

3 0 0
```

```cpp
#include <bits/stdc++.h>
using namespace std;

using int64 = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T; 
    if(!(cin >> T)) return 0;
    while (T--) {
        int n; int64 k; int m;
        cin >> n >> k >> m;
        vector<int64> a(n);
        for (int i = 0; i < n; ++i) cin >> a[i];
        sort(a.rbegin(), a.rend());               // descending

        // prefix sums for fast range sum
        vector<int64> pref(n+1,0);
        for (int i=0;i<n;++i) pref[i+1]=pref[i]+a[i];

        // dp[j] = minimal possible score after processing some prefix,
        // having removed exactly j items and the next kept element will belong to Alice (parity 0) or Bob (parity 1)
        // we keep two states for parity.
        const int INF = 1e9;
        vector<array<int64,2>> dp(m+1, { (int64)4e18, (int64)4e18 });
        dp[0][0]=0; // no element processed, next is Alice

        for (int idx=0; idx<n; ++idx){
            vector<array<int64,2>> ndp(m+1, { (int64)4e18, (int64)4e18 });
            for (int del=0; del<=m; ++del){
                for (int p=0;p<2;++p){
                    int64 cur = dp[del][p];
                    if (cur> (int64)3e18) continue;
                    // 1) delete current item (if we still may)
                    if (del < m){
                        ndp[del+1][p] = min(ndp[del+1][p], cur);
                    }
                    // 2) keep it, add to current player's sum with sign
                    int64 sign = (p==0)? 1 : -1;          // Alice adds, Bob subtracts
                    ndp[del][p^1] = min(ndp[del][p^1], cur + sign * a[idx]);
                }
            }
            dp.swap(ndp);
        }

        // after processing all items, we have for each possible number of deletions the minimal raw score
        // before applying the increase operations.
        // The raw score is Σ_{odd} v_i – Σ_{even} v_i.
        // Now we can increase any kept item, total increase ≤ k.
        // Increasing an item that currently belongs to Alice
        //   (i.e. its sign in the raw score is +1) makes the score larger,
        //   which is never useful for Bob.
        // Increasing an item that belongs to Bob (sign -1) reduces the score,
        //   and the whole effect is exactly the amount of increase.
        // Therefore Bob will spend the whole budget k on items that belong to Bob,
        //   i.e. on the elements that end up on even positions after deletions.
        // Their total contribution can be reduced by at most k, but not below zero.
        // So the final answer for a concrete deletion pattern is:
        //   max( raw_score - k , minimal_possible_score_without_negative )
        // where the lower bound is the raw score after all Bob‑owned items are increased
        // as much as possible (they can be increased arbitrarily, no upper bound).

        int64 answer = (int64)4e18;
        for (int del=0; del<=m; ++del){
            // parity after processing all items is irrelevant; we just need the raw score.
            // The raw score when parity is 0 (next Alice) equals dp[del][0];
            // when parity is 1 (next Alice) equals dp[del][1] because the total number of kept
            // items parity changes the sign of the last kept element, but both are valid final scores.
            int64 raw = min(dp[del][0], dp[del][1]);
            // Bob can decrease the score by at most k using increases on his own items.
            int64 final_score = raw - min(k, (int64) ( -raw < 0 ? 0 : k)); // actually raw may be negative already
            // More simply: the best Bob can achieve is raw - min(k, sum_of_Bob_items_before_increase)
            // but sum_of_Bob_items_before_increase equals the total of absolute values of
            // contributions with sign -1, which is exactly -(raw - sum_all)/2.
            // Computing that exactly is unnecessary because increasing a Bob‑item by x
            // reduces the score by x, and we can always apply the whole k (no upper bound per item).
            final_score = raw - min(k, (int64)k); // i.e. raw - k
            answer = min(answer, final_score);
        }
        cout << answer << '\n';
    }
    return 0;
}
```
