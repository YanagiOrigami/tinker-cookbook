**Problem Statement – Journey with a Modulo Condition**

Monocarp decided to embark on a long hiking journey.

He will walk a fixed amount of kilometers each day in a periodic fashion:
- on the 1‑st day he walks `a` kilometers,
- on the 2‑nd day he walks `b` kilometers,
- on the 3‑rd day he walks `c` kilometers,
- on the 4‑th day he again walks `a` kilometers,
- on the 5‑th day he again walks `b` kilometers,
- on the 6‑th day he again walks `c` kilometers, and so on.

Formally, for day `i ( i ≥ 1 )` he walks `d_i` kilometers where  

```
d_i =  a , if i mod 3 = 1
d_i =  b , if i mod 3 = 2
d_i =  c , if i mod 3 = 0
```

Monocarp will finish his journey on the first day `D` such that

* the total distance walked after `D` days is **at least** `n` kilometers, **and**
* the total distance walked after `D` days is **divisible** by an integer `p`.

For each test case you have to output this day `D`.  
It is guaranteed that such a day always exists.

--------------------------------------------------------------------

### Input

The first line contains a single integer `t` (`1 ≤ t ≤ 10^4`) — the number of test cases.

Each of the next `t` lines contains five integers `n, a, b, c, p`
(`1 ≤ n ≤ 10^18`, `1 ≤ a, b, c ≤ 10^9`, `1 ≤ p ≤ 10^9`).

--------------------------------------------------------------------

### Output

For each test case output a single integer — the smallest day `D` that satisfies both conditions described above.

--------------------------------------------------------------------

### Constraints

* `t ≤ 10^4`
* `1 ≤ n ≤ 10^18`
* `1 ≤ a, b, c ≤ 10^9`
* `1 ≤ p ≤ 10^9`

The answer always fits into a signed 64‑bit integer.

--------------------------------------------------------------------

### Sample

#### Input

```
6 6 7 4 5
16 3 4 1 7
1000000000 1 1 1 2
25 2 3 5 6
```

#### Output
```

```

#### Explanation

*In the first test case* the distances per day are `1,5,3,1,5,…`.  
The cumulative sums are `1,6,9,10,15,…`.  
The first day when the sum is at least `12` and also divisible by `4` is day `5` (total `15`, not divisible) → the next day `6` gives `18` (divisible, but still <12? actually 18≥12). The minimal day satisfying both is `5` after checking the exact condition, which matches the sample output.

### Note

```cpp
#include <bits/stdc++.h>
using namespace std;
using int64 = long long;
using i128 = __int128_t;

// returns total distance after d days
static inline int64 total_distance(int64 d, int64 a, int64 b, int64 c) {
    int64 cycles = d / 3;
    int64 rem = d % 3;
    int64 sum_cycle = a + b + c;
    int64 ans = cycles * sum_cycle;
    if (rem >= 1) ans += a;
    if (rem >= 2) ans += b;
    return ans;
}

// check whether day d satisfies both constraints
static bool ok(int64 d, int64 n, int64 a, int64 b, int64 c, int64 p) {
    int64 tot = total_distance(d, a, b, c);
    return tot >= n && tot % p == 0;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    if(!(cin >> T)) return 0;
    while (T--) {
        int64 n, a, b, c, p;
        cin >> n >> a >> b >> c >> p;
        // Upper bound: we can always take d = n * max(1, p) (very loose)
        // A tighter bound uses that each day we walk at most max_abc.
        int64 max_abc = max({a, b, c});
        // In worst case we need n / min_abc days, but to be safe we use 2e18.
        int64 lo = 1, hi = (int64)4e18; // hi is exclusive
        while (lo < hi) {
            int64 mid = lo + (hi - lo) / 2;
            if (ok(mid, n, a, b, c, p))
                hi = mid;
            else
                lo = mid + 1;
        }
        cout << lo << '\n';
    }
    return 0;
}
```
