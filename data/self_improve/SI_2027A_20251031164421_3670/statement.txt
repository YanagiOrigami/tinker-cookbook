**Problem Statement – Stamp Segmentation**

You are given an infinite square grid, all cells are initially white.  
There are `n` stamps, the `i`‑th stamp is a rectangle of width `w_i` and height `h_i`
(`1 ≤ w_i , h_i ≤ 100`).  
A stamp may be **rotated** by 90 degrees, i.e. you may use it either as `w_i × h_i`
or as `h_i × w_i`.

You have to use every stamp exactly once and you may place a stamp at any
integer position on the grid (the whole rectangle must lie on grid cells).
Different stamps may overlap each other.

The stamps are given in a fixed order `1, 2, …, n`.  
You are allowed to divide this ordered list into several (non‑empty) **consecutive**
groups.  
All stamps belonging to the same group are placed **one after another**,
each possibly overlapping the previous ones, but stamps from different groups
must be placed **after** the previous group is completely finished and must not
overlap any stamp of another group.

For a group let `W` be the maximal width among all stamps of this group
after possibly rotating each stamp, and `H` be the maximal height among all
stamps of this group after the same rotations.
The union of all stamps of the group is completely contained in a rectangle
`W × H`; its outer boundary contributes a perimeter `2·(W+H)`.

The total cost of an arrangement is the sum of perimeters of all groups.
Your task is to minimise this total cost.

--------------------------------------------------------------------
**Input**

The first line contains an integer `t` (`1 ≤ t ≤ 500`) – the number of test cases.  
Then `t` test cases follow.

For each test case

* the first line contains a single integer `n` (`1 ≤ n ≤ 100`) – the number of stamps.
* each of the next `n` lines contains two integers `w_i` and `h_i` (`1 ≤ w_i, h_i ≤ 100`).

--------------------------------------------------------------------
**Output**

For each test case output a single integer – the minimum possible total
perimeter.

--------------------------------------------------------------------
**Constraints**

* `t ≤ 500`
* `n ≤ 100`
* `1 ≤ w_i , h_i ≤ 100`

*Explanation of the first test case*  

All five stamps can be placed in one group.  
After rotating each stamp so that its longer side is horizontal we obtain  

`W = max(5,4,3,4,5) = 5` and `H = max(1,2,3,2,1) = 3`.  
The total perimeter is `2·(5+3) = 16`.  
However, by splitting the sequence into two groups `{1,2,3}` and `{4,5}`
the perimeters become `2·(3+5) = 16` and `2·(5+2) = 14`, total `30`.  
The optimal division is a single group, giving the answer `20`
(see the picture in the original statement).

--------------------------------------------------------------------
**Note**

* Inside a group you may freely rotate each stamp, and stamps may overlap.
* Between different groups no overlap is allowed, which forces the total
  perimeter to be the sum of the perimeters of the groups' bounding
  rectangles.

**Time Limit:** 2 seconds  
**Memory Limit:** 256 MB
