**Problem Statement – “Ruler Queries”**

For every test case there is a hidden integer `x` (`2 ≤ x ≤ 10^9`).  
A faulty ruler works as follows:

* For a true length `y` the ruler reports  

```
y                     , if y < x
y + 1                 , if y ≥ x
```

You may ask a **query** consisting of two positive integers `a` and `b`
(`1 ≤ a , b ≤ 10^9`).  
The jury will measure the sides of an `a × b` rectangle with the faulty
ruler and return the measured area  

```
( a + (a ≥ x) )  ·  ( b + (b ≥ x) )
```

Here `(condition)` is `1` if the condition is true and `0` otherwise.

For each test case you are given **exactly two queries** and their answers.
From this information you have to determine the hidden value `x`.

--------------------------------------------------------------------

### Input

The first line contains a single integer `t` (`1 ≤ t ≤ 10^5`) – the number of
test cases.

Each test case consists of two lines.

* The first line contains three integers `a1 , b1 , s1` – the parameters of the
first query and its reported area.
* The second line contains three integers `a2 , b2 , s2` – the parameters of
the second query and its reported area.

All numbers satisfy `1 ≤ a_i , b_i ≤ 10^9` and the answers are consistent
with some `x` in the range `[2 , 10^9]`.

--------------------------------------------------------------------

### Output

For each test case output a single line with the integer `x`.

--------------------------------------------------------------------

### Constraints

* `1 ≤ t ≤ 10^5`
* `2 ≤ x ≤ 10^9`
* `1 ≤ a_i , b_i ≤ 10^9`
* The given answers are always produced by the described ruler for the same
  hidden `x`.

--------------------------------------------------------------------

### Sample

**Input**
```
3
3 5 18
4 4 25
99 100 9999
99 101 10000
5 5 30
6 6 42
```

**Output**
```
4
100
7
```

**Explanation**

* In the first test case `x = 4`.  
  For the query `(3,5)` we get `(3)·(5+1)=18`, for `(4,4)` we get
  `(4+1)·(4+1)=25`.

* In the second test case `x = 100`.  
  The first answer is `(99)·(100+1)=9999`, the second is `(99+1)·(101)=10000`.

* In the third test case `x = 7`.  
  The first answer is `(5+1)·(5+1)=36` but the input gives `30`,
  therefore the correct offsets are `da = db = 0` for the first query,
  leading to `x > 5`. The second query forces `x = 7`.

--------------------------------------------------------------------

### Note

For a query `(a, b)` let  

```
delta = s – a·b .
```

Only the following four values of `delta` are possible:

* `0`                     – both sides are smaller than `x`;
* `a`                     – only `b` is ≥ `x`;
* `b`                     – only `a` is ≥ `x`;
* `a + b + 1`             – both sides are ≥ `x`.

These four cases give a direct restriction on the possible place of `x`,
allowing the hidden number to be identified after processing the two
queries.

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    if(!(cin >> T)) return 0;
    while (T--) {
        long long a[2], b[2], s[2];
        for (int i = 0; i < 2; ++i) cin >> a[i] >> b[i] >> s[i];

        long long L = 2, R = 1000000000LL;          // current possible interval for x

        for (int i = 0; i < 2; ++i) {
            long long delta = s[i] - a[i] * b[i];
            if (delta == 0) {
                // x > max(a,b)
                L = max(L, max(a[i], b[i]) + 1);
            } else if (delta == a[i] + b[i] + 1) {
                // x <= min(a,b)
                R = min(R, min(a[i], b[i]));
            } else if (delta == a[i]) {
                // only b >= x, thus a < x <= b
                L = max(L, a[i] + 1);
                R = min(R, b[i]);
            } else if (delta == b[i]) {
                // only a >= x, thus b < x <= a
                L = max(L, b[i] + 1);
                R = min(R, a[i]);
            } else {
                // impossible according to statement, but keep safety
            }
        }
        // After two queries the interval is guaranteed to contain exactly one value.
        cout << L << '\n';
    }
    return 0;
}
