**Problem Statement – Non‑Crossing Equal Pairs**

Kinich receives an array `a` consisting of `n` integers (`1 ≤ a_i ≤ n`).  
He wants to choose several *operations*. In one operation he selects two indices
`i` and `j` (`1 ≤ i < j ≤ n`) such that `a_i = a_j` and gains one point.

The chosen operations must satisfy **both** of the following conditions:

1. **Disjointness** – each index can belong to at most one operation.
2. **Non‑crossing** – for any two chosen pairs `(i1, j1)` and `(i2, j2)` we must **not**
   have `i1 < i2 < j1 < j2`. In other words, the intervals `[i1, j1]` and
   `[i2, j2]` cannot intersect unless one is completely inside the other.

Help Kinich obtain the maximum possible total score.

--------------------------------------------------------------------

### Input
The first line contains an integer `t` (`1 ≤ t ≤ 10`) – the number of test cases.

Each test case consists of two lines.

* The first line contains an integer `n` (`1 ≤ n ≤ 500`) – the length of the array.
* The second line contains `n` integers `a_1, a_2, …, a_n` (`1 ≤ a_i ≤ n`).

--------------------------------------------------------------------

### Output
For each test case output a single integer – the maximum score Kinich can achieve.

--------------------------------------------------------------------

### Sample

**Input**
```
5
1
1
2
2 2
2
1 2
4
1 2 3 1
6
1 2 3 1 2 3
```

**Output**
```
0
1
0
1
3
```

**Explanation**

* In the first and third test cases no two equal numbers exist, so the answer is `0`.
* In the second test case the only possible pair is `(1,2)`, giving one point.
* In the fourth test case we can take the pair `(1,4)` (`a_1 = a_4 = 1`);
  any other equal pair would cross it, therefore the answer is `1`.
* In the fifth test case we can take three non‑crossing pairs:
  `(1,4)`, `(2,5)`, `(3,6)` – all values are equal and intervals are nested, so the answer is `3`.

--------------------------------------------------------------------

### Constraints
* `1 ≤ t ≤ 10`
* `1 ≤ n ≤ 500`
* `1 ≤ a_i ≤ n`

--------------------------------------------------------------------

### Note
The problem is equivalent to finding the maximum size of a *non‑crossing matching*
in a sequence where edges are allowed only between equal values.
